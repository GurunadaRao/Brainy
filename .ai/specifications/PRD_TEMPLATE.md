# Product Requirement Document (PRD) Template

## 1. Title & Metadata
- **Feature Name**: [Feature Title]
- **Date**: [YYYY-MM-DD]
- **Author**: [PM Agent / Human]
- **Status**: [Draft / In-Review / Approved]

## 2. Executive Summary
Provide a brief summary of what this feature is, why it is being built, and the core value it delivers.

## 3. Goals & Objectives
- **Target Outcomes**: What does success look like?
- **Non-Goals**: What is explicitly out of scope for this feature?

## 4. User Stories
List user stories in the format:
*As a [User Type], I want to [Action] so that [Benefit].*

- **Story 1**: ...
- **Story 2**: ...

## 5. Functional Requirements
Detailed list of features and functional criteria:
- **Requirement 1**: Description and priority (High/Medium/Low).
- **Requirement 2**: Description and priority.

## 6. Non-Functional Requirements
- **Performance**: Latency, scalability targets.
- **Security**: Auth, access controls.
- **Reliability**: Failover, retry bounds.

## 7. Metrics & Success Indicators
- Key performance metrics (KPIs) to measure.
