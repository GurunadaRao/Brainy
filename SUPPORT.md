# Support Channels

Need help with Brainy 1.0?

1. **GitHub Issues**: Use GitHub Issues for reporting bugs, proposing features, or requesting architectural changes.
2. **Discussions**: For generic integration questions (e.g. *"How do I connect Neo4j with my local credentials?"*), use GitHub Discussions.
3. **Enterprise Support**: For custom integration or professional deployment assistance, contact `support@brainy.ai`.
