# Governance of Brainy 1.0

Brainy 1.0 is an open-source project managed under a consensus-driven contributor model inspired by the Kubernetes and CNCF governance frameworks.

## 1. Project Roles
- **Users**: Anyone running the code or utilizing the Docker builds.
- **Contributors**: Active members opening issues or writing code.
- **Maintainers**: Members with write access to the repository, responsible for merging code and steering architecture.

## 2. Decision Making Process
- **Lazy Consensus**: For minor refactors or bug fixes, standard maintainer reviews apply.
- **Consensus**: Major features or database schema changes require a technical design review template approval from at least two Maintainers.
- **Veto**: Any Maintainer can veto a PR with technical justification. Issues must then be discussed in weekly community syncs.

## 3. Adding Maintainers
- Contributors who demonstrate significant activity (PRs, reviews, support in issues) over a 6-month period may be nominated by an existing Maintainer. Promotion requires a majority vote from current Maintainers.
