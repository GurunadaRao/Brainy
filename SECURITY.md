# Security Policy

## Supported Versions
We actively support security updates for the following versions:
| Version | Supported |
| :--- | :--- |
| 1.0.x | Yes |
| < 1.0.0 | No |

## Reporting a Vulnerability
If you discover a security vulnerability in Brainy 1.0, please do **not** open a public GitHub issue. Instead, report it privately to:
- Email: `security@brainy.ai`

We aim to acknowledge receipt within 48 hours and provide a fix or mitigation plan within 7 days.
